# 🚆 RailAssist

## Intelligent Railway Pension & Settlement Advisory System

RailAssist is an enterprise-grade web application developed for South Central Railway Headquarters.

The platform assists railway employees in calculating retirement settlement benefits while enabling officers to manage Railway rules, circulars and official calculation workbooks.

## Features

- Employee Portal
- Officer Portal
- Settlement Assessment
- Settlement Processing Engine
- Rule Engine
- OPS / UPS / NPS Support
- Railway Circular Management
- Excel Workbook Management
- AI Pension Assistant
- Professional PDF Reports
- Knowledge Base
- Version Controlled Workbooks
