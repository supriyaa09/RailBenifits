# Railway Pension Formula Sheet (OPS / NPS / UPS)

> Consolidated formula sheet prepared from the uploaded Railway
> documents and settlement examples. This file intentionally contains
> formulas only.

------------------------------------------------------------------------

# COMMON

## Emoluments

``` text
Emoluments = Basic Pay + Dearness Allowance
```

## Qualifying Service

``` text
Qualifying Service =
Total Service
- Non Qualifying Service
+ Weightage (if admissible)
```

## Completed Six Monthly Periods

``` text
Completed Six Monthly Periods =
Floor(Qualifying Service in Months / 6)
```

------------------------------------------------------------------------

# OPS

## Pension

``` text
Pension = Last Basic Pay / 2
= 50% × Last Basic Pay
```

## Family Pension

``` text
Family Pension = Last Basic Pay × 30%
```

## Enhanced Family Pension

``` text
Enhanced Family Pension = Last Basic Pay × 50%
```

## Retirement Gratuity

``` text
Retirement Gratuity =
(Basic Pay + DA) × Qualifying Service / 2
```

Equivalent

``` text
Retirement Gratuity =
(Basic Pay + DA) × Completed Six Monthly Periods / 4
```

## Death Gratuity

``` text
QS < 1 Year      = 2 × Emoluments
1 ≤ QS < 5 Years = 6 × Emoluments
5 ≤ QS < 12 Years = 12 × Emoluments
12 ≤ QS < 20 Years = 20 × Emoluments
QS ≥ 20 Years = 0.5 × Emoluments × Completed Six Monthly Periods
```

## Commuted Pension

``` text
Commuted Pension = Pension × Commutation Percentage
```

## Commuted Value

``` text
Commuted Value =
Commuted Pension × 12 × Commutation Factor
```

## Residual Pension

``` text
Residual Pension =
Pension - Commuted Pension
```

## LAP Encashment

``` text
(Basic Pay + DA) × LAP Days / 30
```

## LHAP Encashment

``` text
(Basic Pay + DA) × LHAP Days / 60
```

## Combined Leave Encashment

``` text
Total =
LAP Amount + LHAP Amount

LAP Days + LHAP Days ≤ 300
```

## Provident Fund

``` text
PF =
Employee Contribution +
Government Contribution +
Interest
```

## Composite Transfer Grant (CTG)

``` text
CTG = 80% × Last Drawn Basic Pay
```

## Dearness Relief

``` text
DR = Pension × Current DR Rate
```

## Complimentary Pass

``` text
No mathematical formula.
Eligibility is determined by Railway Pass Rules.
```

# UPS

## Employee Contribution

``` text
10% × (Basic Pay + DA)
```

## Government Contribution

``` text
10% × (Basic Pay + DA)
```

## Additional Government Contribution

``` text
8.5% × (Basic Pay + DA)
```

## Assured Payout

``` text
Assured Payout =
(0.5 × Average Basic Pay of Last 12 Months)
× (Qualifying Service Months / 300)
```

## Minimum Assured Payout

``` text
If Assured Payout < 10000
Return 10000
```

## Admissible Payout

``` text
Admissible Payout =
Assured Payout
× (Individual Corpus / Benchmark Corpus)
× (1 - Final Withdrawal %)
```

## Family Payout

``` text
Family Payout =
60% × Admissible Payout
```

## Lump Sum

``` text
Lump Sum =
(Emoluments / 10)
× Completed Six Monthly Periods
```

## Final Withdrawal

``` text
Maximum Final Withdrawal =
60% × Lower(Individual Corpus, Benchmark Corpus)
```

## Dearness Relief

``` text
DR =
Admissible Payout × Current DR Rate
```
